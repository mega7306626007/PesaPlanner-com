Security information

Last updated: 22 October 2026

This page describes current design choices and known limits. It is not a security certification or a guarantee that any device, network, account or export is risk-free.

Current safeguards

  • Core financial records are stored locally; the app has no cloud-sync account for those records.
  • Android automatic app backup is disabled and cleartext network traffic is disallowed in the current manifest.
  • Subscription verification requests use HTTPS. Paystack handles the mobile-money checkout flow; payment and plan access require an internet connection.
  • SMS import and notification access are optional Android permissions and parsing is performed locally.

Known limitations

The Room database does not use app-level database encryption. The app lock PIN is protected with salted SHA-256, not a slow password-derivation function, and should not be treated as protecting database contents. User-created backup and export files are readable. Keep your device protected and do not share exports unless you intend to.

Report a concern

Email mweshimiwaenterprises@gmail.com with the affected app version, a description and steps to reproduce. Do not include financial statements, passwords, M-Pesa PINs, full payment tokens or another person's data. For personal-data requests, see data deletion; for handling details, see privacy.
