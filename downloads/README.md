# Android APK release slot

Place the signed production Android package here using this exact filename:

`downloads/PesaPlanner.apk`

The website checks for this file and reveals the download button only after it is published. Until then, visitors see the “not available yet” state. Replace the file for each release and keep the public-facing filename unchanged. Publish only the production-signed APK that you intend users to install; do not put debug or test builds here.
